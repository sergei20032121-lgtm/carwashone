# Автомойка №1 — backend (FastAPI) + фронтенд

Рабочий проект: сайт + полноценные личные кабинеты (клиент и админ), запись
по телефону, вход по логину/паролю (и для клиентов тоже), химчистка отдельным
разделом, бонусная карта с ананасами, журнал разовых заказов, 2ГИС-ссылка,
единая дизайн-система на весь сайт.

## Важный фикс в этой версии

Была ошибка «код всегда неверный»: при запросе смс-кода номер телефона
нормализовался (убирались пробелы/дефисы), а при проверке кода — нет, из-за
чего в базе телефон не совпадал сам с собой. Исправлено — нормализация теперь
общая для обоих шагов (`app/schemas.py`, функция `normalize_phone`).

## Структура сайта

- **`index.html`** — главная страница: услуги, химчистка, галерея, бонусная
  карта (витрина), быстрая запись по телефону, ссылки на кабинет и админку.
- **`cabinet.html`** — полноценный личный кабинет клиента: вход **по
  телефону+смс ИЛИ по логину/паролю** (переключатель вкладок), профиль,
  бонусная карта, история записей, форма «задать логин/пароль» (чтобы в
  следующий раз не ждать смс).
- **`admin.html`** — полноценная админ-панель: вход по логину/паролю,
  вкладки Обзор / Записи / Мойки без записи / Химчистка / Услуги / График.
  Из коробки — просмотр и создание заказов, смена статуса записи прямо в
  таблице.
- Общая дизайн-система — `static/css/theme.css` (одна на все три страницы) и
  `static/js/api.js` (общий помощник для запросов к API и хранения токена).

## Дизайн

Убрал неоновый стиль и отдельную анимированную секцию с Mark II — вместо
этого спокойная японская эстетика на весь сайт: тёплая бумага васи (фон),
тушь-суми (тёмные секции), вермильон-печать (акцент/кнопки), приглушённый
нефрit вместо неоновой бирюзы, шрифт Spectral для заголовков. Марк II остался
как маленький, ненавязчивый акцент — штамп-«ханко» (印, стилизованная красная
печать) поверх фото машины в галерее, без анимаций и отдельной секции.

## Как запустить локально

```bash
cd carwash
python -m pip install -r requirements.txt
copy .env.example .env      (на Linux/Mac: cp .env.example .env)
python -m app.seed                                    # демо-данные + админ admin/admin
python -m uvicorn app.main:app --reload --port 8123
```

- Сайт: http://127.0.0.1:8123/site/
- Кабинет клиента: http://127.0.0.1:8123/site/cabinet.html
- Админ-панель: http://127.0.0.1:8123/site/admin.html (admin / admin)
- Swagger (полный список ручек API): http://127.0.0.1:8123/docs
- Смс-коды пока печатаются в консоль сервера — см. `app/sms.py`.

Импорт реальной истории заказов:
```bash
python -m app.scripts.import_uchet "путь/к/Учет.xlsx"
```

## Структура backend

```
app/
  main.py, config.py, database.py, models.py, schemas.py, security.py
  loyalty.py          — логика пуш-карты (ананасы, скидки 50%/100%)
  sms.py              — заглушка смс-провайдера
  dependencies.py     — get_current_user / require_admin / require_staff
  seed.py             — начальные данные
  scripts/import_uchet.py
  routers/
    auth.py           — /auth/otp/*, /auth/login (логин+пароль, любая роль),
                        /auth/set-password (клиент сам привязывает пароль)
    services.py, bookings.py, walk_in.py, dry_cleaning.py,
    schedule.py, reviews.py, admin.py
```
