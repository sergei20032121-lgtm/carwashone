# Автомойка №1 — единый сайт + CRM

Единая рабочая сборка: публичный сайт + полноценные личные кабинеты (клиент,
администратор и руководитель), запись
по телефону, вход по логину/паролю (и для клиентов тоже), химчистка отдельным
разделом, бонусная карта с ананасами, журнал разовых заказов, 2ГИС-ссылка,
единая дизайн-система на весь сайт.

## Объединённый клиентский интерфейс

В этой версии дизайн `carwash-one-site-v2` перенесён внутрь существующей
FastAPI-архитектуры. Команда запуска, маршруты API, SQLite, переменные
окружения и адреса кабинетов не менялись.

- масштабный главный экран с Mark II и беззвучным зацикленным видео;
- интерактивный подбор ухода на основе реальных услуг из CRM;
- каталог с поиском и фильтрами;
- интерактивный «ритуал ухода» и водяные анимации;
- настоящая запись через OTP и свободные слоты backend;
- реальная ананасовая карта авторизованного клиента;
- сохранены CRM, админка, панель руководителя и импорт/экспорт Excel.

## Структура сайта

- **`index.html`** — главная страница: услуги, химчистка, галерея, бонусная
  карта (витрина), быстрая запись по телефону, ссылки на кабинет и админку.
- **`cabinet.html`** — полноценный личный кабинет клиента: вход **по
  телефону+смс ИЛИ по логину/паролю** (переключатель вкладок), профиль,
  бонусная карта, история записей, форма «задать логин/пароль» (чтобы в
  следующий раз не ждать смс).
- **`admin.html`** — полноценная админ-панель: вход по логину/паролю,
  вкладки Обзор / Записи / Мойки без записи / Химчистка / Услуги / График.
  Из коробки — просмотр и создание заказов, смена статуса записи прямо в
  таблице.
- Общая дизайн-система — `static/css/theme.css` (одна на все три страницы) и
  `static/js/api.js` (общий помощник для запросов к API и хранения токена).

```bash
cd carwash
python -m pip install -r requirements.txt
copy .env.example .env      (на Linux/Mac: cp .env.example .env)
python start.py
```

- Swagger (полный список ручек API): http://127.0.0.1:8123/docs

Тестовые входы:

- администратор: `admin` / `admin`;
- руководитель: `manager` / `manager`.

Импорт реальной истории заказов:

## Деплой на Render (и подобные PaaS)

В репозитории уже лежит `runtime.txt` с версией `python-3.11.9`. Это важно:
Render по умолчанию может взять самую новую версию Python (например 3.14),
а для неё у части зависимостей (например `pydantic-core`, собран на Rust)
ещё нет готовых бинарных wheel-пакетов — pip пытается собрать их из
исходников прямо на сервере и падает с ошибкой вида
`Read-only file system` / `maturin failed`. Это не баг в коде проекта,
а несовместимость версии Python с ещё не обновившимися пакетами.
`runtime.txt` жёстко фиксирует Python 3.11, для которого всё ставится
из готовых wheel за секунды.

Настройки веб-сервиса на Render:
- **Build command:** `pip install -r requirements.txt`
- **Start command:** `python -m app.seed && uvicorn app.main:app --host 0.0.0.0 --port $PORT`

Помни: бесплатный тариф Render стирает диск при каждом деплое — поэтому
`python -m app.seed` в start command нужен, чтобы после каждого "холодного"
старта в базе сразу были демо-услуги и админ. Если пароли не указаны через
переменные окружения, seed создаст случайные временные пароли и один раз
выведет их в журнал запуска.

## Новое: ВК-новости + полный CRUD для Учёта и Химчистки

### Учёт (автомойка) и Химчистка — теперь с полным управлением
Обе вкладки в админке (`admin.html`) умеют:
- **Просмотр** — таблица со всеми записями
- **Редактирование** — кнопка «Изменить» на строке подгружает данные в форму,
  дальше это PATCH-запрос (`PATCH /walk-in/{id}`, `PATCH /dry-cleaning/orders/{id}`)
- **Удаление** — кнопка «Удалить» (только для роли admin)
- **Экспорт в .xlsx** — кнопка «⬇ Экспорт», скачивает текущий журнал файлом
- **Импорт из .xlsx** — кнопка «⬆ Импорт», формат — тот же, что у экспорта
  (открыл в Excel → поправил/добавил строки → загрузил обратно)

Это отдельно от `app/scripts/import_uchet.py` — тот скрипт для одноразовой
миграции твоего исходного многолистового "Учёт.xlsx", а экспорт/импорт в
админке — для повседневной работы (бэкап, массовое редактирование, перенос
между базами).

### Новости ВКонтакте
- Вкладка «Новости ВК» в админке: домен группы + access token + кнопка
  «Синхронизировать» — подтягивает последние посты со стены через VK API
  (`wall.get`), включая прикреплённые фото.
- Секция «Новости» на главной странице сайта показывает синхронизированные
  посты автоматически.
- **Токен не хранится в git.** Задаётся либо через `.env` (`VK_ACCESS_TOKEN`,
  `VK_GROUP_DOMAIN`), либо прямо через вкладку «Новости ВК» в админке (тогда
  он живёт только в базе данных сервера). Если ты присылал токен в переписке —
  имей в виду, что он уже "засвечен"; если это тебя смущает, можно перевыпустить
  новый в настройках сообщества ВК (Управление → Работа с API → Ключи доступа).
- Проверить синхронизацию я не смог из своей среды — у неё ограниченный список
  разрешённых доменов для исходящих запросов, и `api.vk.com` в него не входит.
  На твоём сервере интернет открыт полностью, так что там всё отработает —
  просто нажми «Синхронизировать» в админке и посмотри на результат.

## Большое обновление: реальный прайс, роль «Руководитель», рефералка и остальное

### Прайс — актуализирован по карточке 2ГИС
Полностью переписан в `app/seed.py`: у услуг появилась вилка цен (`price_from`/
`price_to`), и у каждой — `payout_pct=35` (35% от суммы услуги начисляется
автоматически при завершении заказа/записи).
Правило бонусной карты подтверждено: «Комплексная (полная) мойка» и всё, что
дороже — ставит ананас; всё, что дешевле или на её уровне (Облив, Бесконтактная,
Экспресс, Сухой туман, Жидкий воск) — без ананаса.

### Новая роль — Руководитель (`manager.html`)
Отдельный логин `manager` с временным или заданным через `.env` паролем, доступ **только
на чтение** — физически не может ничего создавать/менять/удалять (проверено:
попытка что-либо изменить возвращает 403). Дашборд показывает: выручку,
прибыль (оценка), средний чек, цену программы лояльности (сколько "подарили"
скидками 50%/100% за период), прогресс к цели по выручке за месяц, рейтинг
сотрудников, структуру выручки мойка/химчистка.

### Личный кабинет клиента — новые разделы
- **Мои машины** — сохранённые авто, можно добавлять/удалять
- **Приведи друга** — персональная ссылка вида `?ref=КОД`; когда по ней
  регистрируется новый клиент — ананас капает и ему, и пригласившему
- **День рождения** — просто дата, дальше это можно использовать для акций
- **Подарочные сертификаты** — купить (генерируется код `GIFT-XXXXXXXX`) и
  погасить чужой код
- **Бейдж стажа** («Новый клиент» / «С нами N мес.» / «С нами N г.»)
- **Оценка мастера** — после выполненной записи в истории появляются звёзды 1-5

### Админ-панель — новые вкладки
- **Поиск клиента** — по номеру телефона, вся история одним экраном (записи +
  разовые заказы + химчистка)
- **Журнал изменений** — кто и что создавал/менял/удалял, с именем сотрудника
- **🖨 Печать списка на смену** — кнопка в разделе «График», обычная печать
  браузера с отдельными print-стилями (остальной интерфейс на печати скрыт)

### Что делать после разворачивания
1. Смени пароли `admin`/`admin` и `manager`/`manager` сразу после первого входа
2. Зайди в `manager.html` и проверь, что дашборд открывается и не даёт ничего менять
3. Проверь `?ref=` — открой сайт по реферальной ссылке, зарегистрируйся новым
   номером и убедись, что у пригласившего появился ананас

## Капитальная переработка: учёт по сотрудникам, зарплата, окно записи

### Много сотрудников на одну машину
Новая таблица `JobAssignment` — на любой заказ (Учёт / Химчистка / Запись)
можно назначить нескольких сотрудников через кнопку **«👥 Сотрудники»** в
админке (открывает чек-лист с мультивыбором). 35% (или свой `payout_pct`
у услуги) делится между назначенными поровну.

### Движок зарплаты (`app/payroll.py`) — тестовый режим
Реализовано и проверено на реальных цифрах:
- 35% с машины делится поровну между всеми назначенными на неё сотрудниками
- Админ на смене (сотрудник с флагом `is_admin_role`, у которого есть смена
  в этот день) получает 5% от **всей** выручки дня + 1000₽ фиксированно.
  Если админ ещё и сам мыл конкретную машину — за неё получает и обычную
  долю тоже, в дополнение к надбавке
- Гарантия дня: если у сотрудника по итогу дня набралось меньше 1000₽ —
  ему доплачивается ровно до 1000₽
- Отчёты: `GET /admin/payroll/daily?day=...` и `GET /admin/payroll/weekly?date_from=...&date_to=...`,
  доступны и админу, и руководителю (только чтение). В админке — вкладка
  «Зарплата», в `manager.html` — блок «Индивидуальная зарплата за день»

Все проценты и суммы настраиваются через `BusinessSettings`
(`admin_shift_pct`, `admin_shift_fixed`, `daily_guarantee_amount`).

### Права руководителя расширены
Теперь может (в дополнение к дашборду):
- Менять график смен (`PUT /schedule`) — блок «Сотрудники и график» в `manager.html`
- Редактировать данные сотрудников (`PATCH /schedule/employees/{id}`) и
  скрывать их (`DELETE`, деактивация)
- Видеть индивидуальную зарплату каждого

При этом по-прежнему НЕ может трогать записи, журналы Учёта/Химчистки и
услуги — это осталось только у admin/master.

### Окно записи клиента — 3 дня онлайн, дальше по телефону
- `POST /bookings` для роли `client` отклоняет запись дальше
  `client_booking_window_days` (по умолчанию 3) дней вперёд с понятной
  ошибкой; для персонала (admin/master) ограничения нет
- `GET /bookings/slots` возвращает `within_online_window` и `max_online_date`,
  плюс шаг слотов теперь берётся из настройки `slot_granularity_minutes`
  (60/30/15/10 минут) вместо жёстко зашитых 30

### Прайс — редактирование прямо в админке
Вкладка «Услуги» теперь с полноценной формой (название, категория, цена
«от»/«до», минуты, % сотрудникам, ставит ли ананас, описание) — Swagger
для этого больше не нужен.

### Что уже посеяно из коробки
- Отдельный сотрудник **«Администратор»** с флагом `is_admin_role=True`,
  привязанный к аккаунту `admin` — по нему и считается 5%+1000₽/день
- Всем сотрудникам на сегодня проставлена смена «Полный день» — чтобы
  дневной отчёт по зарплате сразу показывал живые данные после первого запуска

## Причёсываем «Учёт»: время, журнал по дням, полное управление сотрудниками

### Учёт (автомойка) — теперь настоящий журнал по дням
- Добавлено поле **«Время»** в форму (раньше его не было вообще — только дата)
- Таблица заменена на **журнал, сгруппированный по дням**, ровно как в
  твоей исходной таблице: заголовок дня показывает "Администратор дня: Х",
  строки — время / авто / услуга / кто мыл (чипы сотрудников), внизу каждого
  дня — строка «Итого за день» с суммой выручки и суммой зарплаты
- Добавлен фильтр периода (по умолчанию — последние 7 дней), чтобы журнал не
  разрастался на сотни строк без разбора

### Убрали ручной ввод «З/п мастера»
Раньше при создании заказа химчистки нужно было руками вписывать сумму
зарплаты — это лишнее и рассинхронизировалось с реальным расчётом. Теперь
поле убрано из формы полностью: зарплата целиком считается автоматически
(35%, делится между назначенными сотрудниками), назначение — той же кнопкой
«👥 Сотрудники».

### Пикер сотрудников — стал приятнее
Вместо списка чекбоксов — кликабельные чипы с подсветкой; у тех, кто может
быть «админом смены», рядом корона 👑.

### Полное управление сотрудниками — и у руководителя, и у админа
Раньше можно было поменять только цвет бирки. Теперь доступно (в `admin.html`
и `manager.html`):
- **Добавить** сотрудника (имя, должность, флаг «админ смены»)
- **Редактировать** любого — имя, должность, включить/выключить флаг
  «может быть админом смены» (важно: **любой сотрудник может быть админом
  смены**, это независимый флаг, а не привязка к должности)
- **Удалить** (деактивировать)

Проверено вживую от лица руководителя: добавил нового сотрудника, поменял
роль другому на «Администратор» с флагом `is_admin_role=true`, удалил —
всё отработало (200 OK на каждом шаге).

- `frontend/static/img/gallery/*.jpg` — общая фотогалерея на главной
- `frontend/static/img/drycleaning/*.jpg` — фото "до/после" в разделе химчистки

Чтобы заменить/добавить фото:
1. Положи новый файл в нужную папку (можно поверх старого с тем же именем,
   можно с новым именем — тогда файлов станет больше)
2. Если добавил файл с НОВЫМ именем — открой `frontend/index.html`, найди
   похожий блок `<div class="gallery-item">...<img src="static/img/gallery/ИМЯ.jpg" ...>`
   и либо поправь путь у существующего, либо скопируй такой блок целиком
   и вставь новый со своим путём/подписью (`gallery-cap`)
3. Пересобери и задеплой как обычно (коммит → пуш → редеплой на хостинге)

Про видео: сам HTML/CSS/JS-стек это прекрасно умеет (обычный тег `<video>`),
просто пока файла с видео в проекте нет. Если пришлёшь mp4-файл (или ссылку
на него) — добавлю блок с видео в нужное место сайта на следующем заходе.
Самому вставить видео можно так же, как с фото: положить файл в
`frontend/static/video/` и заменить `<img>` на:
```html
<video src="static/video/твой-файл.mp4" autoplay muted loop playsinline></video>
```

## Премиальные фичи (без скидок и без "тикающего" счётчика — по договорённости)

Все новые фичи используют только реальные данные из базы — никакой имитации
фейковой активности, это было бы обманом клиента.

### Новый backend-роутер `app/routers/public_stats.py`
- `GET /public/recent-activity` — реальная активность за последние 6 часов,
  анонимизированная ("Иван Петров" → "Иван П."). Если событий нет — пустой список.
- `GET /public/busy-hours` — загруженность по часам за 30 дней (реальная
  статистика по Учёту и Записям). `has_data:false`, если данных ещё мало.
- `GET /public/current-load` — "свободно / небольшая загрузка / загружены"
  прямо сейчас, по количеству активных броней рядом с текущим временем.

### На главной странице
- Кастомный курсор-капля + мыльный след из пузырьков (десктоп, отключается
  при `prefers-reduced-motion`)
- Магнитные CTA-кнопки (`.btn-magnetic`)
- Дышащий индикатор загрузки + тепловая полоска часов-пик в hero
- Скролл-эффект "смыв грязи" — полупрозрачный тонированный слой на hero
  тает по мере скролла
- Честный тост "недавняя активность" в углу экрана — только реальные заказы
- Баннер "твоя машина скучает" — для клиента, у которого последняя мойка
  была давно (сессия помнит, если баннер закрыли)
- Сезонный совет (зима/весна/лето/осень) — без скидок, просто польза
- XP-полоска над бонусной картой — прогресс до 50%/100% визуально как шкала опыта

### В личном кабинете
- Блок "Достижения" — Первая мойка, 5 полных моек, 12+ моек, Ночная сова
  (запись после 21:00), Ранняя пташка (до 9:00), Пригласил друга, День рождения указан
- Тактильная вибро-обратная связь (`navigator.vibrate`) — при успешной
  записи, оценке мастера, копировании реферальной ссылки (плавно деградирует
  на устройствах без поддержки вибрации — просто ничего не делает)
- Тот же кастомный курсор и магнитные кнопки
