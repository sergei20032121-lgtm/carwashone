# Обновление V20 — касса и оплаты

- Добавлен единый раздел «Касса» для записей, заказов без записи и химчистки.
- В кассе отдельно показаны сумма заказов, фактически полученные деньги, подтверждённые долги и неразобранные операции.
- Поддерживаются наличные, карта, перевод, сертификат и заказ без оплаты.
- Для заказа можно поставить статусы: не отмечено, оплачено, частично, долг или без оплаты.
- Все изменения оплаты попадают в журнал действий CRM.
- Старые заказы после обновления остаются со статусом «не отмечено»: система не придумывает способ оплаты задним числом.
- Существующая SQLite обновляется автоматически при запуске. Настройки, команды запуска и структура проекта не менялись.
- Экран кассы адаптирован для телефона: показатели складываются в сетку, а операции превращаются в компактные карточки.
