# Обновление V13 — вода и грязь только на кузове

- Добавлена отдельная маска силуэта Toyota Mark II.
- Грязный слой теперь накладывается только на автомобиль.
- Стены, пол, освещение, логотип-ананас и интерфейс не затрагиваются.
- Убраны мультяшные капли и яркая вертикальная «стена воды».
- Вода отображается как узкий мокрый блик непосредственно на кузове.
- Ползунок, автоматический запуск и кнопка повтора сохранены.
- Для мобильной версии используется та же маска с отдельным масштабированием.
- Главная фраза сохранена: «Моем. Бережём. Доводим до идеала».
