# Обновление V23

- Исправлено смещение первого экрана влево: контейнер hero снова имеет безопасные боковые поля на широких и мобильных экранах.
- В карточке адреса добавлен узнаваемый знак «2ГИС».
- Рабочие фотографии разделены по смыслу:
  - мойка — кузов, пена, диски и арки, уборка салона;
  - детейлинг — полировка кузова, восстановление оптики и пластика;
  - химчистка — отдельный раздел с собственным прайсом и примерами.
- Убраны спорные подписи поверх рабочих фотографий.
- Восстановлена контрастность заголовка «Химчистка».
- Переписан текст этапа ручной работы без фразы про «конвейерную спешку».
- В калькулятор добавлена отдельная задача «Глубоко очистить салон».
- При выборе «Сделать по максимуму» калькулятор больше не подменяет результат расширенной обычной мойкой: для быстрого ухода рекомендует детейлинг/полировку.
- Обновлён офлайн-кэш до V23.

Архитектура проекта, команды запуска и серверные настройки не менялись.
