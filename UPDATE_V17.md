# Обновление V17 — CRM

- На главном экране CRM добавлен оперативный обзор текущей смены: записи, ожидание подтверждения, машины в работе, оборот дня и ближайший клиент.
- Добавлены быстрые переходы к записям, новому заказу, поиску клиента и мобильному режиму мастера.
- Записи теперь фильтруются одновременно по поиску и статусу.
- Отфильтрованный список записей можно выгрузить в CSV с русскими заголовками.
- Поиск клиента превращён в карточку CRM: оборот, количество визитов, последний визит, бонусный прогресс, звонок, копирование телефона и переход к записям клиента.
- В истории клиента отображаются названия услуг вместо внутренних идентификаторов.
- Новые CRM-блоки адаптированы под мобильный экран.
- Фотоотчёты не добавлялись.
- FastAPI, SQLite, `.env`, API и запуск через `python start.py` не менялись.
