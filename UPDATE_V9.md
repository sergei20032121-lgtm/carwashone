# Обновление V9 — интерактив и рабочая CRM

Архитектура проекта сохранена: FastAPI, существующая база, переменные окружения,
`start.py`, адреса API и роли пользователей не менялись.

## Сайт

- Ближайшие свободные окна выводятся в первом экране из `/bookings/slots`.
- Нажатие на время открывает запись с уже выбранными днём и слотом.
- Подбор услуги стал трёхшаговым: тип автомобиля, задача, приоритет.
- Добавлены два сенсорных слайдера «до/после» из реальных рабочих фотографий.
- Эффект воды усилен откликом на касание без видео и тяжёлого canvas.
- После успешной записи появляется короткая ананасовая анимация.
- Все новые блоки имеют отдельную мобильную компоновку и поддержку клавиатуры.
- Для пользователей с `prefers-reduced-motion` лишние анимации отключаются.

## CRM

- Во вкладке «Записи» появилась канбан-доска:
  «ожидает» → «подтверждена» → «в работе» → «выполнена».
- На компьютере карточки перетаскиваются мышью.
- На телефоне статус переводится кнопкой «дальше».
- Обычная таблица сохранена и доступна переключателем.
- Любое изменение статуса использует прежний `PATCH /bookings/admin/{id}`.

## Совместимость

- Миграции базы не нужны.
- Старые `.env` и настройки сервера подходят без изменений.
- Запуск: `python start.py`.
- Тестовый режим: `admin/admin` и `manager/manager`.
