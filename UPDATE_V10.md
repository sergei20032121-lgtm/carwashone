# Обновление V10 — рабочий экран администратора

Архитектура и способ запуска не изменены. Миграции базы не требуются.

## Записи

- API записи теперь дополнительно возвращает имя и телефон клиента, название
  услуги и её длительность. Это вычисляемые поля из существующих связей.
- Канбан показывает реальные названия вместо числовых ID.
- Добавлены быстрый звонок клиенту и переход к следующему статусу.
- Записи фильтруются по сегодняшнему дню, завтрашнему или выводятся все.
- Поиск работает по клиенту, телефону, услуге и комментарию.
- Над доской появилась почасовая диаграмма загрузки с 09:00 до 20:00.
- Табличный режим сохранён и использует те же фильтры.

## График

- Добавлена недельная сетка всех сотрудников.
- Есть переходы на предыдущую, текущую и следующую неделю.
- После сохранения смены сетка обновляется автоматически.
- Выходной и невыход визуально отличаются от рабочей смены.
- На телефоне сетка прокручивается горизонтально, а канбан фиксируется по колонкам.

## Совместимость

- `python start.py`, `.env`, SQLite/PostgreSQL и прежние URL API сохранены.
- Тестовые доступы в `TEST_MODE=true`: `admin/admin`, `manager/manager`.
